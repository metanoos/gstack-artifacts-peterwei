## Affected Pages/Routes
- **Write mode (desktop + mobile)** — manuscript editor with trace gutter. Verify `EditorPort` double-logging prevention holds; `apply-editor-value!` requires a typed writer-decided application binding for every programmatic write. (src/zine/editor.cljd, test/zine/editor_test.cljd)
- **Replay mode** — scrub/seek through trace. Verify replay preconditions (sequence, revision, deleted-text) reject tampered/missing/duplicate evidence. (src/zine/trace.cljd)
- **Compare mode** — branch reconciliation. Verify concurrent sessions get explicit fork nodes, never a fake global order. (src/zine/cross_device.cljd)
- **Diagnostic app surface** — the `PROOF SLICE` labeled panels in main.cljd are the current runnable proof, not a shipped product.

## Key Interactions to Verify
- **Editor fidelity (real keyboards — Gate 1):** CJK/accented IME composition, autocorrect, dictation, paste, selection replacement, undo/redo, large-document latency, exact trace replay. Status is `:real-device-verification-required` (editor.cljd:19-25) — widget tests exercise the simulated text-input channel but CANNOT satisfy this gate. **Must be run on real macOS, Chrome, iOS, Android.**
- **Undo/redo as linked reversals:** verify undo appends a reversal event, never rewrites earlier evidence; redo resolves the exact linked reversal. (editor_test.cljd)
- **Clipboard exactly-once:** web clipboard waits for an explicit copy action; native clipboard threshold uses worker-preflight draft bytes; CJK and emoji byte counts are UTF-8-correct. (main_test.cljd)
- **Web artifact budget admission:** oversized artifacts fail BEFORE payload work and disclose the worker gap; admitted artifacts yield a frame before running payload. (main_test.cljd)

## Edge Cases
- **Trace tampering:** mutated deleted-span evidence must yield `:unknown-event-semantics`, not a silent replay. (trace_test.cljd)
- **Checkpoint corruption:** invalid periodic checkpoint is ignored and rebuilt from last valid + immutable events; full replay does not trust a later checkpoint over earlier history.
- **Duplicate event IDs:** fail closed across device strands and within a single session.
- **Impossible beat budget:** selector fails instead of dropping disclosure or inventing coverage.
- **Blind evaluation injection:** duplicate participant votes, favorable subsets, and missing/conflicting bindings all fail to produce an official release result. (evaluation_test.cljd)

## Critical Paths
- **Write → trace → replay:** every editor-boundary `TextEditingValue` transition becomes a replayable trace event; replay reconstructs exact delivered text, selection, and composing state.
- **Saved locally ≠ synced:** `JournalStore` acknowledges a revision only after the durable barrier; network sync is a separate state. Verify the two indicators never lie.
- **Concurrent offline work:** stays concurrent; becomes explicit branches shown side by side; never auto-merged or last-writer-wins.
- **Selector → presentation (GAP, see eng-review D3):** the beat selector passes its fixtures but is NOT wired to presentation. Until D3 lands, document-scale automatic cuts do not use the beat budget.

## Deferred-adapter E2E (GAP — adapters not built)
- **Sync transport:** missing-causal-parent envelopes remain pending; authentication/integrity failure quarantines and blocks editing on dependent frontiers. Contract defined in ports.cljd; adapter deferred.
- **Model dispatch:** BYOK routes, pre-dispatch privacy findings, cost/fan-out budgets, progressive trust ladder. Harness compiles projections; dispatch adapter deferred.
- **Vault durability:** authenticated encryption + framing, startup recovery discards incomplete trailing transaction back to last acknowledged boundary. Contract defined; native journal adapter deferred (README "planned slice-2").

## LLM/Eval (GAP — no live model calls yet)
- Eval suites are DEFINED in evaluation.cljd (blind preference, comprehension, attribution) but not run against a real provider. When the model adapter lands, run the defined cohorts against the preregistered criteria before any automatic-cut release claim.
